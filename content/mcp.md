::: title
MCP & Network Telemetry
:::

::: desc
Agents inspect the emulated network through Model Context Protocol (MCP) tools.
:::

::: server1_title
Network Telemetry
:::

::: server1_tools
- `ping_pair` / `traceroute`: reachability and paths
- `iperf_test`: bandwidth between hosts
- [Pingmesh](https://doi.org/10.1145/2785956.2787496): packet loss and round-trip time
- `int_query_telemetry`: per-hop traces in supported P4 networks
:::

::: server3_title
Packet Capture
:::

::: server3_tools
- `packet_capture_start`: capture network traffic
- `packet_capture_stop`: end a capture
- `packet_capture_inspect`: inspect packets and protocols
:::

::: server5_title
Routing Diagnostics
:::

::: server5_tools
- BGP and OSPF configuration
- BGP session state
- Routing tables
:::
